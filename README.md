# LabReserve

Sistema web local para consultar e reservar laboratórios e equipamentos.

## Requisitos

- Node.js 22.13 ou superior (o projeto usa `node:sqlite` nas histórias de persistência).
- npm 10 ou superior.

## Comandos

```bash
npm install
npm run dev
npm test
npm run typecheck
npm run lint
npm run build
npm run test:e2e
```

A aplicação ainda está na fase inicial de implementação. Consulte [IMPLEMENTATION_PLAN.md](IMPLEMENTATION_PLAN.md) para a sequência TDD aprovada e [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) para as decisões arquiteturais.
